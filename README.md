#  Green Screen Effect using OpenCV (Python)

This project demonstrates a **real-time green screen (chroma key) effect** using Python and OpenCV.
Any green-colored area in the webcam feed is replaced with a background image of your choice.

No advanced setup required — just plug and play.

---

##  What This Project Does
- Detects **green color** in real time using HSV color space
- Replaces green areas with a custom background image
- Works with a normal webcam
- Lightweight and easy to understand

---

##  How to Use Your Own Background Image (Very Important)

You can use **ANY image you like** as the background.

### Steps:
1. Choose any image (JPG / JPEG recommended)
2. Rename the image to: background.jpeg
3. Place it in the **same folder** as the Python script

That’s it — no code changes needed.


---

## 📦 Requirements
- Python 3.8 or above
- Webcam
- Green cloth or green background
