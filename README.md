# Green Screen Effect using OpenCV (Python)

This project implements a real-time **green screen (chroma key) effect** using OpenCV.
A live webcam feed replaces green-colored regions with a custom background image.

## Features
- Real-time green color detection using HSV color space
- Background replacement using a static image
- Noise reduction using morphological operations
- Simple and lightweight implementation
